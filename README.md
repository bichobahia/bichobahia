# Olá! Aqui é o Bicho Bahia 👋

Repositórios open source mantidos pela equipe do [Bicho Bahia](https://bichobahia.com.br/), portal informativo sobre o jogo do bicho na Bahia.

### Projetos

| Repositório | Descrição |
|---|---|
| [descubra-o-bicho](https://github.com/bichobahia/descubra-o-bicho) | Ferramenta online: digite uma milhar e veja centena, dezena e grupo |
| [tabela-jogo-do-bicho](https://github.com/bichobahia/tabela-jogo-do-bicho) | Os 25 grupos e suas dezenas em JSON e CSV |
| [horarios-paratodos-bahia](https://github.com/bichobahia/horarios-paratodos-bahia) | Grade de extrações em formato aberto |
| [bicho-estatisticas](https://github.com/bichobahia/bicho-estatisticas) | Script para calcular frequência de grupos a partir de um CSV |

### Tecnologias

PHP · MySQL · JavaScript · HTML/CSS · coleta e organização de dados
